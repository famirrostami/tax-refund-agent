# Germany
- Tax authority and portal: Finanzamt, ELSTER. Annual return is the Einkommensteuererklärung; employee costs go in Anlage N (Werbungskosten).
- Categories: home office (Homeoffice-Pauschale, Arbeitszimmer), work equipment (Arbeitsmittel, geringwertige Wirtschaftsgüter, depreciation), commute (Pendlerpauschale), other (Fortbildung, Spenden, Krankheitskosten and similar).
- Always state the tax year. Rules change between years; use only rules from `packs/de/rules` for that year.
- Check against the Werbungskosten-Pauschbetrag: individual costs only help if the total exceeds the standard allowance. Mention this.
- Use German form and line names alongside the user's language, since the user will type values into ELSTER.
